# Vespra Relay

Built-in color, file, and product icon themes for Vespra Code.

## Themes

- **Vespra Relay Dark** — product default. Deep ink surfaces with a lime relay accent.
- **Vespra Relay Light** — cool paper surfaces with olive accent.
- **Vespra Relay Contrast** — high-contrast dark variant.

Also contributes **Vespra Relay Files** and **Vespra Relay Product** icon themes.
