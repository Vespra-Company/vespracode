# Features

Tracker for what Vespra Code changes relative to upstream Code OSS. Three lists, one file each:

| File | Meaning |
|---|---|
| [ideas.md](ideas.md) | Not committed to. Anything goes. |
| [planned.md](planned.md) | Agreed; not shipped yet. Has an owner or a branch. |
| [implemented.md](implemented.md) | On `main`. Link the PR. |

Move an entry between files as it progresses; do not duplicate it. For anything that needs more than a paragraph, create `features/<slug>.md` and link it from the list.

Entry format:

```
- **Name** — one-line summary. (owner / branch / PR)
```
