# Discussions

Working notes, Q&A and design conversations for the Vespra team. Anything here is informal; promote decisions into `../ARCHITECTURE_BLUEPRINT.md` or `../features/` once they are settled.

## Conventions

- One file per topic, named `YYYY-MM-DD-short-topic.md`.
- Start each file with a one-line `Status:` (open, answered, decided, superseded).
- Keep a `## Notes and follow-ups` section at the bottom for comments.
- Link to code with repo-relative paths in backticks so they stay searchable.
